# Legal Clause Simplifier AI

## What This Does
This AI tool takes hard legal language and explains it in simple English. It uses a smart system (Llama 3 + QLoRA) to learn from examples.

## Why It's Useful
- Makes contracts easier to understand
- Works on a single computer (no big servers needed)
- Learns from your legal documents

## How I Built It
1. **Base AI**: Llama 3 (8B version)
2. **Efficient Training**: QLoRA (only updates small parts)
3. **Memory Saving**: 4-bit compression

## What You Need
- Python 3.8+
- NVIDIA GPU (24GB+ memory works best)
- Hugging Face account (free)
